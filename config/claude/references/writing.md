# Japanese Writing Style

## Spacing Around English Words

- When inserting English words or symbols into Japanese text, add a half-width
  space before and after them
- Example: `GitHub の Cognito`（`GitHubのCognito` にしない）

## Parentheses

- Always use half-width parentheses `()` with a half-width space before and
  after, regardless of whether the content inside is Japanese or English
- Example: `Cognito (AWS の認証サービス) を利用する`（`Cognito（AWS の認証サービス）を利用する` にしない）

## Emoji

- Don't use emoji unless the user explicitly asks for them
- This restates Claude Code's default behavior explicitly so it holds even if
  that default changes
